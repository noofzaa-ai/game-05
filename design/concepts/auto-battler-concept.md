## 1. What the game is
An auto-battler in the style of Teamfight Tactics **(Boss, 2026-11-10)**. The player arranges a squad before the fight; in the fight the characters walk up to the monsters and fight by themselves. The player cannot move or press skills.

## 2. Core loop (as built)
```
Class cards (pick/dress a squad of 3) → fight on a small floating-island board
→ waves of goblins arrive (12 waves, the last one a boss) → squad heals a bit each wave
→ win/lose summary → back to the cards
```
- **Squad:** 3 fighters per round. All share one body; the **class is an animation set plus a fighting style** (`data/classes/*.json`, `data/combat/weapons.json`).
- **Fight:** `logic/auto_pilot.gd` plays for our fighters through the normal rules (same input as a human). It walks to the nearest enemy, guards or dodges attacks that are about to land, steps out of marked ground circles, uses the ultimate when the gauge is full, and otherwise chains light hits with a heavy finisher. Shooters stand off at about 6 m.
- **Waves:** `data/journeys/goblin_waves.json`: one stage, 12 waves, monster counts x1.5, wave power scale 0.6, the squad is healed 40% each wave, the last wave is the Goblin Chief boss.
- **Camera:** frames the whole board; zooming in follows one fighter (click a squad card or press 1-3).
- **HUD:** empty except 3 squad cards (HP + ultimate gauge).

All numbers are placeholders until the Boss plays (project rule). Longbow/Magic have no weapon model in hand yet.

## 4. Player fantasy
Collecting and dressing class cards, then watching the summoned squad win. **(Boss)**: "summon a card onto the board" feel; cartoon look; landscape screen; Teamfight-Tactics-style island board with a zoomable 3D view.
**Progression (Boss, 2026-11-11):** a card gives the player more than dressing and squad choice: **new items, equipment, fashion and boss drops, like an RPG**. So the loot, gear and fashion systems stay in the game.

## 5. What works / what needs work
- **Works (verified by tests, 2026-11-11):** the squad of Great Sword + Longbow + Magic clears all 12 waves on two seeds; classes change the fighting style; shooters fire projectiles; picking a card changes the camera target.
- **Needs work:** class balance (never measured), the weapon models and sounds for the new classes (sounds reuse blade), the class-card screen and the summon scene, the post-win summary for wave mode, an unexplained `Parameter "material" is null` error in real stages, slow frame rate on the old Mac.
- **Dropped (Boss):** manual play, the old hub (bonfire) screen and the farm/camp/shop, old character animations, all weapons except blade, reviving downed allies.

## 6. Decisions and open questions
**Decided (Boss, 2026-11-11):**
1. **Old systems: cut them all** — farm, camp, shop, hub/NPC. (Not done yet: the hub is still the way into the game until the class-card screen replaces it; deleting is a separate task, see Follow-up.)
2. **Launch content:** 3 classes at the start — Sword & Shield, Great Sword, Bow. **Magic unlocks after a few quests.** (The code today starts the squad as Sword & Shield, Great Sword, Magic, and there are no quests yet: both differ from this decision.)
3. **Co-op is not needed yet**, but the game must be designed so the simulation runs in **headless Godot** (server-authoritative). `logic/` is already pure rules with no nodes, which supports this.
4. **Project goal:** hobby / portfolio (`project.goal: hobby`).
