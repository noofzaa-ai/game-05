# Combat number atlas

Generated by `python3 tools/ui/build_combat_numbers.py` from Changa One Italic (Google Fonts, SIL OFL1.1; source/license in art_source/fonts/changa-one). One1024x512 RGBA PNG, about111KB, shared by all digits. Rows: white normal, orange critical, green +heal, red incoming damage. Incoming damage overrides crit orange for the local player. No runtime font or per-hit nodes/tweens. Fixed64slots; pop/float/fade and bounded stacking in client/combat_numbers.gd. Values follow actual damage events; healing observes net positive HP changes and aggregates regen. HP gains cancelled by damage between observed snapshots cannot be displayed separately; presentation only, no invented gameplay events.
