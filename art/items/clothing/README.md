# ชุดตัวละครใน Studio

วาง GLB กับ sidecar JSON ชื่อเดียวกันใน `art/items/clothing/` พร้อม PNG สำหรับรูปการ์ด

ใช้ `slot` เป็น `head`, `shirt`, `arms`, `pants` หรือ `shoes` ไฟล์ต้องมี skin weight และ bind pose ตรงกับตัวฐาน Chibi ปัจจุบัน ดูรายละเอียดใน `art/items/README.md` ปลอกแขนคู่เป็น GLB ช่อง arms แยกจากเสื้อ

## ปลอกแขนแยก

- `clothing_knight_bracers_01.glb` — อัศวิน
- `clothing_scout_bracers_01.glb` — ลาดตระเวน
- `clothing_sentinel_bracers_01.glb` — องครักษ์
- `clothing_infernal_bracers_01.glb` — รัตติกาลดำแดง
- `clothing_mage_sleeves_01.glb` — แขนเสื้อจอมเวทบาน ใช้ช่อง arms
- `clothing_oathkeeper_bracers_01.glb` — ปลอกแขนหนังชุดพิทักษ์ พร้อมแผ่นหลังมือ
- `clothing_raven_bracers_01.glb` — ปลอกแขนหนามชุดอีกา พร้อมแผ่นหลังมือ
- `clothing_artificer_cuffs_01.glb` — แขนเสื้อผ้าช่างกลบาน พร้อมแผ่นหลังมือผ้า
- `clothing_ember_wraps_01.glb` — ผ้าพันแขนสีขาวชุดนักสู้เพลิง
- `clothing_orchid_cuffs_01.glb` — ปลอกแขนผ้าม่วงชมพูชุดกล้วยไม้

ทุกชิ้นมี JSON และ PNG ชื่อเดียวกัน ปลอกแขนตาม LowerArm ของแต่ละข้าง ส่วนแผ่นหลังมือของชุดพิทักษ์ตาม Hand เสื้อยังเก็บส่วนไหล่และต้นแขนไว้ ส่วนข้อศอก/ปลอกแขน/สายรัดข้อมืออยู่ในไอเทม arms

สามชุดแรกคง ID แต่ asset_version เป็น 2 เสื้อไม่รวมปลอกแขนแล้ว Godot ต้องประกอบช่อง arms เพิ่ม ภาพและ GLB ก่อนปรับเก็บใน `tools/image_to_3d/.cache/armor_revisions/before_bracers_20261006/` ชุดรัตติกาลสร้างแยกช่องตั้งแต่ asset_version 1

รายละเอียด: `knight_armor.md`, `scout_armor.md`, `sentinel_armor.md`, `infernal_armor.md`, `mage_robe.md`, `oathkeeper_armor.md`, `raven_armor.md` ในโฟลเดอร์นี้ ชุดจอมเวทเป็นผ้าและใช้ weight ผสมช่วงลำตัว/เข่า ต่างจากแผ่นเกราะแข็งชุดก่อน

เลือกสลับเป็นรายช่องใน Studio ได้ รหัสไอเทมคงเดิมสำหรับ mapping ใน Godot ชุดเกราะเหล่านี้ไม่มี cloth simulation และยังไม่ได้ตรวจการใช้งานใน Godot

รายละเอียดชุดผ้าช่างกล: `artificer_cloth.md` เสื้อใช้ weight ผสมตามลำตัว ชายชุดแยกขา และรองเท้า blend ช่วงข้อเท้า

ชุดนักสู้เพลิงมี 4 ช่อง ไม่มีเครื่องประดับหัว ดู `ember_outfit.md` รองเท้าแตะมีเท้าเปล่ารวมในชิ้น shoes เพื่อแสดงหน้าเท้าเมื่อ Studio ซ่อนเท้าของตัวฐาน

ชุดผ้ากล้วยไม้ม่วงชมพู: `orchid_silk.md` เสื้อและผ้าคลุมผสม weight ตามลำตัว ชายผ้าแยกตามขา ปลอกแขนและรองเท้าผสมบริเวณข้อต่อ ใช้ skin deformation ไม่มี cloth physics

ชุดผ้ากล้วยไม้เทาดำ: `orchid_ash.md` เป็นสีแยก 5 ID เปลี่ยนเฉพาะสี material ใช้ geometry และ skin weights เดียวกับสีม่วงชมพู

ชุดผ้ากล้วยไม้เทาลายส้ม: `orchid_grayorange.md` เป็นอีกสีแยก 5 ID ผ้าเทา ขอบดำ ลายปักส้ม ใช้รูปทรงและ rig เดิม

ชุดผ้ากระเรียนขาวแดง: `crane_outfit.md` มีปีกประดับหัว เสื้อ แขนเสื้อบาน ชายผ้า และรองเท้าผ้า เสื้อผสม weight ตามลำตัว/ศอก ชายชุดแบ่งตามขา ไม่ใช่ cloth physics

ชุดผ้าตัวตลกแดงขาว: `jester_outfit.md` แยกหมวก เสื้อ แขนเสื้อพอง กางเกง และรองเท้าปลายงอน แขนเสื้อทั้งต้นแขน/ท่อนล่างอยู่ใน `clothing_jester_sleeves_01.glb` ช่อง arms ใช้ weight ผสมตรงศอก รองเท้าใช้ weight ผสมหน้าแข้ง/ข้อเท้า
