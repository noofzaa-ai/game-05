# zorx → Auto-battler: สรุปทุกอย่างที่คุยกับ Boss (ส่งต่อเครื่องใหม่)

อัปเดตล่าสุด 2026-11-11 · repo `https://github.com/noofzaa-ai/game-05` branch `main`
ไฟล์นี้คือ "สิ่งที่ดูจากโค้ดไม่ได้": ทิศทาง คำสั่ง Boss เหตุผล และงานค้าง อ่านคู่กับ `PROGRESS.md` (ท้ายไฟล์) และ `CLAUDE.md`

## 1. ทิศทางเกม (Boss ตัดสินแล้ว)

- **เปลี่ยนแนวเป็น Auto-battler (แนว Teamfight Tactics):** ผู้เล่นจัดทัพก่อน แล้วในฉากสู้ตัวละครวิ่งเข้าไปตีกับมอนเองทั้งหมด **ผู้เล่นขยับหรือกดสกิลเองไม่ได้**
- **ทัพละ 3 ตัวต่อรอบ** ทุกตัวใช้โมเดลฐานเดียวกัน (ตัวละครจาก test05/studio) **คลาส = ชุดแอนิเมชัน** ที่ใส่ให้ตัวเดียวกัน
- **สนามเล็กพอดีจอ** เหมือนเกาะลอยฟ้า (Boss ชอบ TFT) บรรยากาศใช้ assets ค่าย goblin เดิม ไม่ใช่สนามฟุตบอลเปล่าๆ กล้องเห็นทั้งเกาะและ **ซูมเข้าไปดูตัวละคร 3D สู้กันได้**
- **จอแนวนอน** (ลองจอตั้งแล้ว Boss ไม่เอา เพราะมุมบนเกินไป)
- **UI ในฉากสู้ต้องโล่ง** ไม่มีปุ่มสกิล/Guard/Dodge มีแค่การ์ดทัพ 3 ใบล่างจอ (HP + เกจอัลติ)
- **โหมดเวฟแทนการวาป:** ด่านเดียว 12 เวฟ เวฟสุดท้ายเป็นบอส มอนเพิ่ม ×1.5
- **การ์ดคลาส (Class Card):** ทุกคนมีการ์ด = จำนวนคลาสในเกม (ตอนนี้ 4) แต่ละใบแต่งตัวละครข้างในต่างกัน (ผม ตา ชุด ตัว; สกิลมาทีหลัง) การ์ดมีตัวละคร 3D เล่นท่า idle ของคลาสอยู่ข้างใน ให้ฟีลเหมือน **อัญเชิญการ์ดลงสนาม**
- **หน้ากองไฟเดิม (วิ่งเล่น คุย NPC) จะถูกรื้อ** เปลี่ยนเป็นหน้าการ์ดแทน
- **หน้าการ์ดต้องเป็นแนวการ์ตูน** (Boss ปฏิเสธแนวทองเหลืองเวทมนตร์)
- **UI (ปุ่ม กรอบ panel) ให้อีกทีมทำ** ตามสเปก `docs/ui/class_card_ui_handoff.md` ซึ่ง Boss บอกให้ทำได้เลย
- รื้อของเก่า: **ลบแอนิเมชัน/ท่าตีของตัวเก่าทั้งหมด** เหลือแค่ของตัวใหม่ **อาวุธเหลือ blade อย่างเดียว** (และมือเปล่าสำรอง)
- Boss สั่ง "ไม่ต้องถามแล้ว อธิบายมากพอแล้ว": ให้ตัดสินใจตามค่าเริ่มต้นที่สมเหตุสมผลแล้วทำต่อ ถามเฉพาะเรื่องใหญ่จริงๆ

ผลเทสต์ล่าสุด: **2389 ผ่าน / 159 พัง** ทั้ง 159 ข้อพังอยู่ก่อนแล้ว (baseline) ตอนเทียบผล ให้เทียบรายชื่อข้อที่พัง ไม่ใช่ดูแค่จำนวน

## 3. งานต่อไป (เรียงตามลำดับ)

1. **`client/card_portrait.gd`**: SubViewport แสดงโมเดล 3D เล่น idle ของคลาสในกรอบการ์ด ใบที่เลือกอยู่เรนเดอร์ทุกเฟรม ใบอื่นเรนเดอร์ช้าลง (ห่วงเรื่องประสิทธิภาพบนเว็บ) API ตามสเปก §3/§13: `set_class`, `set_look`, `set_hover`, `pulse`
2. **ผูกหน้าการ์ดของทีม UI** (`client/card_deck_screen.gd` + `scenes/card_deck_screen.tscn`): signal → คำสั่ง `card_look`/`card_squad` → `show_deck()` แล้วให้เกมเปิดหน้านี้แทน `GameState.go_hub()` ส่วน NPC/ฮับเดิม **ซ่อน ไม่ลบ**
3. **ฉากอัญเชิญ**: การ์ดบินลงกระดาน → แฟลช → ตัวละครโผล่ที่จุดเกิด
4. **ตรวจหน้าสรุปหลังชนะในโหมดเวฟ** (`journey_screen`) รางวัล ของดรอป และเสียง `wave_arrived`
5. **ให้คลาสมีผลต่อกติกา** ตอนนี้ทุกคลาสยังใช้สถิติ/สกิล/ระยะของ blade ต้องทำต่อ: Longbow ยิงไกล, Magic ร่ายเวท, ระยะพุ่งของแต่ละคลาส และโมเดลอาวุธ Longbow/Magic ที่ยังไม่มี
6. **AI ช่วยชุบเพื่อนที่ล้ม** และ **กล้องซูมตามตัวที่เลือก** (ตอนนี้ตามแค่ผู้เล่น 1)
7. **ตัด repo ระดับ 2**: ลบโค้ดและอาร์ตระบบเก่า (ตัวละครเก่า `characters/base`, `character.glb`, ผม/ชุดเก่า `items/hair`, `items/clothing`, ฮับ NPC ร้าน ฟาร์ม, แมพที่ไม่ใช่ goblin) จะเหลือราว 200–250 MB (ตอนนี้ราว 560 MB) แนะนำให้ทำตอนรื้อฮับเป็นหน้าการ์ด
8. **ออนไลน์** ยังเป็นแบบบังคับเอง (RemoteSession) ยังไม่รองรับ auto-battle

## 4. เรื่องที่ยังรอ Boss / ควรรู้

- repo `game-05` เป็น **PUBLIC** ถ้าไม่ตั้งใจให้คนทั่วไปเห็น ให้เปลี่ยนเป็น private
- ฟอนต์ **Mitr** ในสเปกการ์ด: ผมเลือกเองตอน Boss บอกว่า "ทำได้เลย" ยังไม่ได้ใส่ลงในเกม
- ข้อความภาษาไทยบนหน้าการ์ด (ชื่อคลาส, "ออกรบ!") ผมตั้งเอง Boss แก้ได้
- ตัวเลือกแต่งตัวมีเท่าที่ Studio มีจริง: ผม 5 แบบ, ชุด 2 แบบ, สีตา 4 สี + กำหนดเอง, เมคอัพ 2 แบบ, สีผิว 4 สี + กำหนดเอง **ไม่มีรูปทรงตาให้เลือก** ถ้าอยากได้เพิ่มต้องให้ทีมโมเดลทำ
- error `Parameter "material" is null` ขึ้นตอนรันด่านจริง ยังไม่รู้ต้นเหตุ และเฟรมเรตบนเครื่อง Mac เครื่องเดิมค่อนข้างช้า
- กฎ parity กับ Studio ใน `CLAUDE.md` ยังใช้อยู่: รายการตัวเลือกต้องดึงจาก Studio จริง ห้ามคิดขึ้นเอง

## 5. ย้ายเครื่อง: ต้องทำอะไรบ้าง

1. `git clone https://github.com/noofzaa-ai/game-05.git zorx` (repo นี้ไม่มีประวัติเก่า ประวัติเต็มอยู่ที่ `github.com/grislyhub/zorx`)
2. **ไฟล์ที่ไม่ได้อยู่ใน git ต้องคัดลอกเอง:**
   - `data/online.local.json`: คีย์เชื่อมเซิร์ฟเวอร์จริง (ถ้าไม่มี เกมจะเข้าโหมดออฟไลน์เงียบๆ)
   - `art_source/` (858 MB): ไฟล์ต้นฉบับ Blender/PSD ใช้เฉพาะตอนแก้อาร์ต
   - โฟลเดอร์ Studio ต้นฉบับ `test05/studio` (~192 MB เดิมอยู่ `/Users/user/godot-project/test05/studio`): ต้องใช้ตอนนำเข้าคลาส/ผม/ชุดเพิ่ม (ไฟล์ที่ใช้แล้วถูกคัดลอกไว้ใน `art/characters/studio05/`)
   - `build/k3s-remote/releases/`: ข้อมูล rollback ของ deploy เก่า (ถ้าจะ deploy)
3. ติดตั้ง Godot 4.7.2 แล้วรัน `godot --headless --path . --import` ครั้งแรก (นำเข้า GLB/ภาพ)
4. รันเทสต์: `godot --headless --path . --script res://tests/run_all.gd` ต้องตั้งตัวจับเวลา (บน Mac ไม่มี `timeout` ให้ใช้ `perl -e 'alarm 900; exec @ARGV' <godot> ...`) แล้วเทียบข้อที่พังกับ baseline 159 ข้อ
5. ความจำของ Claude: คัดลอก `docs/handoff/claude_memory/*.md` เข้าโฟลเดอร์ memory ของเครื่องใหม่ (`~/.claude/projects/<path ของโปรเจกต์>/memory/`) ตาม CLAUDE.md
6. ภาพตรวจในเกม: `tools/shots/auto_battle_shots.gd` (env `JOURNEY`, `ZOOM`) และ `tools/shots/studio05_classes.gd` ต้องรันแบบมีหน้าต่าง ไม่ใส่ `--headless`
