# ข้อกำหนดโมเดลตัวละคร (ส่งให้ทีมศิลป์)

เกมออนไลน์บนเว็บ เล่นบนมือถือและ PC ใช้ Godot โมเดลต้อง **เบา แยกชิ้นได้ และมีแอนิเมชัน** เพื่อรองรับระบบสวมอุปกรณ์ 14 ช่อง

## ผลตรวจไฟล์ `character.glb` ที่ได้รับ (2026-10-03)
| หัวข้อ | ที่ได้รับ | เป้าหมาย | สถานะ |
|---|---|---|---|
| สไตล์ภาพ | low-poly การ์ตูน น่ารัก | stylized low-poly | ตรงแนว |
| จำนวนสามเหลี่ยม | **138,420** (413,640 จุด) | ไม่เกิน **6,000** ทั้งตัว | หนักเกิน ~23 เท่า |
| ขนาดไฟล์ | **22.4 MB** | ไม่เกิน **1 MB** | หนักเกิน |
| ชิ้นส่วน | **ชิ้นเดียวทั้งตัว** (เสื้อ กางเกง รองเท้า ผม รวมกัน) | แยกชิ้นตามช่องอุปกรณ์ | สลับเกราะไม่ได้ |
| โครงกระดูก | 17 ข้อ ชื่อมาตรฐาน (hips, spine, chest, neck, head, แขน/ขา ซ้ายขวา) | ใช้ได้ | ผ่าน |
| แอนิเมชัน | **ไม่มี** | ชุดท่าด้านล่าง | ยังไม่มี |
| พื้นผิว | 1 รูป PNG 334 KB, 1 วัสดุ | รวมเป็น atlas 1 รูป | ผ่าน |
| ความสูง | 1.99 หน่วย จุดกำเนิดอยู่กลางลำตัว | 1.8 หน่วย จุดกำเนิดอยู่ที่เท้า | เกมปรับให้อัตโนมัติแล้ว |
| ทิศหน้า | หันไปทางแกน +Z (ถูกต้องตามมาตรฐาน glTF) | +Z | ผ่าน |

ตัวไฟล์ปัจจุบันใช้ **ทดสอบในเกมได้** (ผมต่อเข้ากับตัวละครผู้เล่นแล้ว ใช้ท่าทางคำนวณจากโค้ดแทนแอนิเมชัน) แต่ **ใช้ขึ้นเว็บจริงไม่ได้**

## สิ่งที่ต้องขอจากทีมศิลป์
### 1. ลดความหนัก
- ตัวละครเปล่า (ไม่รวมอุปกรณ์) ไม่เกิน **4,000** สามเหลี่ยม และรวมอุปกรณ์สวมใส่ครบไม่เกิน **8,000**
- ชิ้นอุปกรณ์แต่ละชิ้น (หมวก เสื้อ ฯลฯ) ไม่เกิน **800 ถึง 1,500** สามเหลี่ยม
- ใช้สไตล์เหลี่ยมแบบเดิมได้เลย (รูปลักษณ์ปัจจุบันเข้ากับเกมอยู่แล้ว ขอแค่ลดจำนวนหน้า)
- เชื่อมจุดที่ซ้ำกัน (weld vertices) ตัวปัจจุบันมีจุดเกือบ 3 เท่าของที่ควร

### 2. แยกชิ้นส่วน (สำคัญที่สุดสำหรับระบบอุปกรณ์)
แยกเป็นวัตถุ (mesh) คนละชิ้น ผูกกับโครงกระดูกเดียวกันทั้งหมด:
`body` (ผิวเปล่า รวมหัว มือ) · `hair` · `hat` · `shirt` · `pants` · `shoes` · `armband` (ชิ้นเดียว มีทั้งแขนซ้ายและขวา) · `back` (ของสะพายหลัง) · `weapon` (อาวุธ ติดกับกระดูกมือ)
- ใต้ชิ้นเสื้อผ้าต้องมีผิวเต็ม (ไม่เว้าว่าง) เพราะเกมจะสลับหรือซ่อนเสื้อผ้า
- ต่างหู สร้อย กำไล แหวน เป็นช่องที่ให้ค่าสถานะอย่างเดียว ยังไม่ต้องทำโมเดล

### 3. โครงกระดูก
- ใช้ 17 ข้อเดิม ชื่อตามเดิมทุกตัวอักษร (`hips spine chest neck head upper_arm.L forearm.L hand.L upper_arm.R forearm.R hand.R thigh.L shin.L foot.L thigh.R shin.R foot.R`) ทุกตัวละครต้องใช้โครงเดียวกัน
- เพิ่มจุดยึดอุปกรณ์ (กระดูกหรือ empty) ชื่อ: `attach_weapon.R` `attach_weapon.L` `attach_back` `attach_head`
- จุดกำเนิดของโมเดลอยู่ที่ **เท้า** (พื้น) ความสูงตัวละคร 1.8 หน่วย (เมตร) หันไปทาง +Z

### 4. แอนิเมชัน (อยู่กับที่ ไม่เคลื่อนที่ไปข้างหน้าเอง ไม่ใช้ root motion)
ตั้งชื่อตามนี้ เฟรมเรต 30 หรือ 60:
| ชื่อ | หมายเหตุ |
|---|---|
| `idle` | วนซ้ำ |
| `walk` | วนซ้ำ |
| `jump_up` `jump_fall` `land` | กระโดด |
| `light_1` `light_2` `light_3` | คอมโบเบา 3 ท่า ความยาวท่าตามข้อมูลต่อสู้ (ดูด้านล่าง) |
| `heavy` | ท่าหนักตีให้ลอย |
| `air_attack` | โจมตีกลางอากาศ |
| `hurt` | โดนตี (สั้น) |
| `launched` | ลอยกลางอากาศ |
| `down` `getup` | ล้มนอน / ลุก |
| `death` | ตาย |
| `guard` `dodge` | ป้องกัน / หลบ (เมื่อกติกาตัดสินแล้ว) |
- **ความยาวท่าโจมตีต้องตรงกับข้อมูลต่อสู้** (60 เฟรม = 1 วินาที): `light_1` และ `light_2` = 17 เฟรม (เตรียม 4 โดน 3 พัก 10) · `light_3` = 24 (5/3/16) · `heavy` = 38 (12/4/22) · `air_attack` = 15 (3/4/8) เฟรม "โดน" คือช่วงที่ชุดโจมตีทำความเสียหายจริง ถ้าท่าไม่ตรง ผมปรับตัวเลขในเกมให้ตรงกับแอนิเมชันได้

### 5. ไฟล์และพื้นผิว
- ส่งเป็น `.glb` ส่งออกจาก Blender (Apply transforms, +Y up, ไม่ต้องบีบอัด Draco)
- พื้นผิวรวมเป็น **atlas รูปเดียว** ขนาดไม่เกิน 512x512 พิกเซล (ถ้าต้องการรายละเอียดหน้าตา อาจใช้ 1024 เฉพาะส่วนหัว)
- ตั้งชื่อวัสดุและวัตถุเป็นภาษาอังกฤษ ไม่มีช่องว่าง

## ทดสอบก่อนส่ง
เปิดไฟล์ใน Blender ตรวจ Statistics (Overlays > Statistics) จำนวน Triangles ต้องอยู่ในเกณฑ์ข้างบน
